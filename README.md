# PAN7420 无人机飞控与遥控器系统

基于 **PY32F030（ARM Cortex-M0+）** 的四轴飞控 + 2.4G 遥控器双工程，含配套的 C / C++ 学习示例。

> **项目性质说明**：本项目为嵌入式学习与实践项目。飞控与遥控器的**原有工程代码来自配套教学工程**，
> 本人完成的部分为：控制链路梳理与联调、驱动适配与调试、注释规范化与工程文档建设，
> 以及用 CMake + GCC 替代 Keil 重建可复现的编译流程。文末「本人工作范围」有详细说明。

---

## 硬件

| 部件 | 型号 | 说明 |
|---|---|---|
| 主控 | PY32F030（Cortex-M0+，48MHz） | 飞控与遥控器各一片 |
| 姿态传感器 | ICM42688 | 六轴 IMU，SPI 接口 |
| 气压计 | BMP390 | 高度测量，SPI 接口 |
| 射频 | PN298 | 2.4G 双向链路，软件 SPI |
| 电机驱动 | 四路 PWM | TIM3 四通道，16kHz |

芯片与模组手册见 `docs/`（PY32F030 datasheet / reference manual、PAN742x 产品说明书、PN298 用户手册）。

## 系统架构

```
  ┌──────────────────────────┐                    ┌──────────────────────────────┐
  │  遥控器（发射端）          │   12 字节上行包     │  飞控（飞机）                 │
  │  摇杆/按键 → joystick.c   │   0xAA 指令/0xDB对码 │  第4层 应用  user/main.c      │
  │  → deal_data.c 组包       │ ─────────────────► │  第3层 业务  user/*.c, imu/fc.c│
  │  → PN298 2.4G            │ ◄───────────────── │  第2层 算法  imu/imu.c(Mahony) │
  │                          │   12 字节下行 ACK   │        imu/pid.c, altitude.c  │
  └──────────────────────────┘   （遥测/低压标志）  │  第1层 驱动  accgyro/bsp_pwm   │
                                                   │  第0层 底层  PY32F0xx HAL     │
                                                   └──────────────────────────────┘
```

**一句话数据流**：遥控器把摇杆位置打成 12 字节射频包发给飞机；飞控解包得到指令，
读取 IMU 与气压计算出姿态与高度，经 PID 与混控算出四个电机的占空比，再回一个 ACK 给遥控器。

### 飞控核心模块

| 模块 | 职责 |
|---|---|
| `imu/imu.c` | 姿态解算（Mahony 互补滤波） |
| `imu/pid.c` | 姿态控制（角度环 → 角速度环 → 混控） |
| `imu/altitude.c` | 气压 + 加速度互补融合、定高 PID |
| `imu/filter.c` | PT1 一阶低通、biquad 二阶低通、滑动平均 |
| `imu/fc.c` | 飞行状态机（解锁 / 起飞 / 降落判定） |
| `imu/decode.c` | 遥控指令换算（fcCmd[] → rcCommand[]） |
| `imu/accgyro.c` | ICM42688 驱动：量程 / ODR 配置、零偏校准 |
| `user/bsp_pwm.c` | 四路电机 PWM 输出（TIM3，16kHz） |
| `user/common.c` | BMP390 气压计驱动 |
| `drivers/bsp/` | PN298 射频、串口、SPI |

## 构建

工程提供 CMake 配置，可用 GCC 工具链交叉编译（替代原 Keil 工程）：

```bash
cmake -B build-gcc -DCMAKE_TOOLCHAIN_FILE=<arm-none-eabi-toolchain.cmake>
cmake --build build-gcc
```

- 工具链：`arm-none-eabi-gcc`
- 依赖：PY32F0xx HAL 驱动（随工程提供）
- `CMakePresets.json` 内含预设配置
