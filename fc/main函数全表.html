三、按「周期」看 main.c 的调度（理解它的关键）#

main.c 本体只是个调度器：TIM17 每 1ms 给几个计数器 +1，主循环比对阈值来决定该谁干活。

触发条件实际周期跑哪些函数归属文件
_cnt10ms >= 10约 11msdecode_pack() + annexCode()user/deal_pack.c、imu/decode.c
_cnt4ms >= 4约 5msMode_Controler()（空翻状态机）user/flip.c
每一圈约 4.6msaltitude_ctrl()（2.1~3.9ms）+ flight_ctrl()（2.5~3.4ms）imu/altitude.c、imu/fc.c
_cnt100ms >= 100约 101ms喂狗 HAL_IWDG_Refresh() + Led_Process()HAL、user/led.c
_cnt1s >= 1000约 1.001sget_voltage()（读电池电压）user/adc.c
每一圈—失联检测（>5000ms）→ 报警 + bLanding=1 + bsp_pn298_rx_mode()HAL、user/led.c、drivers/bsp/bsp_pn298.c
每一圈—油门低位且 accData[2]>6000 → 自动解锁（motorArmed=1）imu/fc.c 的 fc 结构

两条最容易搞错的地方（已在 术语解析手册.md 11.6 节记录）： 1. 控制环不在 1ms 中断里，而在主循环；1ms 只是时基。实测主循环一圈约 4.6ms。 2. 周期实际是 N+1 ms（判断是「先比较再清零」，而中断在同一毫秒内还会 +1）。
