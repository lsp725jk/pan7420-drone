## 一、全景：两个工程、四层结构

```
  ┌──────────────────────────────────────────────────────────────┐
  │  遥控器（发射端）                                             │
  │    摇杆/按键 → joystick.c → deal_data.c 组包 → PN298 2.4G    │
  └───────────────────────────┬──────────────────────────────────┘
                              │ 12 字节上行包（0xAA 指令 / 0xDB 对码）
                              │ 12 字节下行 ACK 载荷（遥测/低压标志）
                              ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  飞控（飞机）                                                 │
  │                                                              │
  │  第4层 应用    user/main.c        初始化顺序 + 主循环调度      │
  │  第3层 业务    user/*.c           对码、包解析、灯语、空翻、电压 │
  │                imu/fc.c           飞行状态机                  │
  │  第2层 算法    imu/imu.c          姿态解算（Mahony）          │
  │                imu/pid.c          姿态控制（角度→角速度→混控）│
  │                imu/altitude.c     高度融合 + 定高             │
  │                imu/filter.c       数字滤波                    │
  │  第1层 驱动    imu/accgyro.c      ICM42688                   │
  │                user/common.c      BMP390                     │
  │                user/bsp_pwm.c     电机 PWM                   │
  │                drivers/bsp/*.c    射频 PN298、串口、SPI        │
  │  第0层 底层    PY32F0xx_HAL_Driver + cmsis（厂商库，当黑盒看）  │
  └──────────────────────────────────────────────────────────────┘
```

**一句话**：遥控器把摇杆变成 12 字节射频包；飞控收到后解成内部指令，
读传感器算出姿态，用 PID 算出四个电机该转多快，再回一个 ACK 给对方。

## 四、主循环怎么调度（理解整个飞控的关键）

`main.c` 本体只是**调度器**：TIM17 每 1ms 给几个计数器 +1，主循环比对阈值决定该谁干活。

| 触发条件 | 实际周期 | 跑什么 | 文件 |
| --- | --- | --- | --- |
| `_cnt10ms >= 10` | 约 11ms | `decode_pack()` 收遥控 + `annexCode()` 换算指令 | `user/deal_pack.c`、`imu/decode.c` |
| `_cnt4ms >= 4` | 约 5ms | `Mode_Controler()` 空翻状态机 | `user/flip.c` |
| **每一圈** | **约 4.6ms** | `altitude_ctrl()`（定高）+ `flight_ctrl()`（姿态控制） | `imu/altitude.c`、`imu/fc.c` |
| `_cnt100ms >= 100` | 约 101ms | **喂狗** + `Led_Process()` 刷灯 | `user/WDG.c`、`user/led.c` |
| `_cnt1s >= 1000` | 约 1.001s | `get_voltage()` 读电池 | `user/adc.c` |
| 每一圈 | — | 失联检测（>5000ms 没收到包 → 自动降落） | `main.c:470` |
| 每一圈 | — | 油门低位且飞机平放 → 自动解锁 | `main.c:432-448` |

### ⚠ 两条最容易看错的地方

1. **控制环不在 1ms 中断里，而在主循环。** TIM17 中断（`drivers/bsp/bsp_timer.c`）
   **只做计数器自增**；`flight_ctrl()` 的唯一调用点是 `main.c:410`。
   1ms 是**时基**，不是控制周期 —— 实测主循环一圈约 **4.6ms**。
   （工程里有 7 处注释曾写成「在 TIM17 中断里」，已更正。）
2. **周期实际是 N+1 ms。** 判断是「先比较后清零」，而中断在同一毫秒内还会 +1，
   所以 `_cnt4ms>=4` 实际约 5ms、`_cnt100ms>=100` 实际约 101ms。

## 五、数据怎么流（三条链路）

### 5.1 遥控指令：从摇杆到电机

```
  遥控器                          飞控
  ──────                          ────
  ADC 采摇杆                       bsp_pn298_rx_data_ack_fix()  收 12 字节
     ↓ joystick_filter_map()          ↓ 校验 0xAA + device_ID
  hardware_value[0..3]             rx_buff[2..9] → ch_value[0..3]
     ↓ Send_Remote_Data()             ↓ 减中位 1500
  send_pn298_pack[12]              fcCmd[ROLL/PITCH/THROTTLE/YAW]
     ↓ 射频发送                        ↓ annexCode()  imu/decode.c
      ──── 2.4G ────►                rcCommand[4]（油门1000~2000 / 目标量）
                                       ↓ flight_ctrl()  imu/fc.c
                                     pid()  imu/pid.c
                                       ↓ 角度环 → 角速度环 → 混控
                                     motorPWMValue[4]  user/bsp_pwm.c
                                       ↓ TIM3 四路 PWM
                                     四个电调
```

### 5.2 姿态：从传感器到角度

```
  ICM42688 ──SPI1──► accgyro.c ──► accData[3] / gyroData[3]（LSB）
                                       ↓ filter.c（陀螺 PT1 240Hz、加速度 biquad 30Hz）
                                     imu.c
                                       ↓ Mahony 互补滤波（Kp=0.25 / Ki=0.0025）
                                     四元数 → rMat 旋转矩阵
                                       ↓ imuUpdateEulerAngles()
                                     angle[0..2]（单位「度×100」）
                                       ↓ pid.c  target_angle = 20*rcCommand
                                     姿态控制
```

### 5.3 高度：气压 + 加速度融合

```
  BMP390 ──SPI1──► common.c ──► baroPressureAvg（中值5点 + 滑动平均6点）
                                    ↓ 换算成高度（baro_pow_0p295）
                                  BaroAlt
                                    ↓ 互补滤波（α=0.985）
  加速度 Z ──积分──► accAlt ────────►
                                    EstAlt（毫米）
                                    ↓ 定高 PID（位置环 → 速度环）
                                  BaroPID ──► 混控里叠加到油门上
```

## 八、建议的读代码路线

按「从外到内」的顺序，每一步都能独立看懂：

1. **`user/main.c`** —— 先用第三节的时序表对着读，明白「上电先干什么」。
2. **`user/main.c:379` 的主循环** —— 明白任务是按计数器分派的，以及周期是 4.6ms 而不是 1ms。
3. **`user/deal_pack.c`** —— 一个 12 字节包怎么变成 `fcCmd[]`。这里能看懂通信协议。
4. **`imu/decode.c`** —— `fcCmd[]` 怎么变成 `rcCommand[]`（指令的含义在这一层变化）。
5. **`imu/fc.c`** —— 状态机（解锁/起飞/降落）+ 它按什么顺序调下面三个。
6. **`imu/imu.c`** —— 传感器数据怎么变成姿态角（Mahony 互补滤波）。
7. **`imu/pid.c`** —— 姿态角怎么变成四个电机的占空比（角度环→角速度环→混控）。
8. **`imu/altitude.c`** —— 高度怎么融合、定高怎么叠加到油门。
9. **`user/WDG.c` + `user/led.c`** —— 安全与提示（看门狗、灯语）。

> **为什么按这个顺序**：1~2 建立「程序骨架」，3~5 建立「数据怎么进来、
> 状态怎么管」，6~8 才是算法。**先骨架后算法**，读起来不容易迷路。
